# Module 2 milestone: a reusable prompt for a task you repeat

## What to produce

Build, test and save one reusable prompt for a task you do regularly at work, such as a weekly update, a type of customer reply, meeting preparation or a standard summary.

1. Choose the task. It should be something you will do at least monthly.
2. Start with a plain request and note what a stranger would have had to guess.
3. Add the goal, the audience and the constraints, including at least one "must not".
4. If style or format matters, include two examples or a skeleton.
5. Improve the result over several rounds of specific feedback.
6. Ask the assistant to write the prompt that would have produced the final result first time, with [brackets] for the parts that change.
7. Test that prompt in a new chat with different details.

Bring to the module session:

- Your first plain request and what it produced.
- The final reusable prompt.
- The output from your test run in a new chat.
- One sentence on the correction that made the biggest difference.

If you had the assistant interview you, also bring the question you found hardest to answer.

## How you know it is good

- The task is real and recurring, and you expect to use the prompt again.
- The prompt states a goal, an audience and constraints. Someone else on your team could use it and get a similar result.
- The test run in a new chat produced a first draft that needed only light editing.
- Every fact in the output came from what you supplied. The prompt tells the assistant what to do when information is missing.
- Nothing confidential is built into the prompt itself. The details that change go in the brackets.
- You can say which of your corrections ended up in the prompt, and why.
